Ringkasan : 
Praktikum clustering menggunakan algoritma K-Means untuk mengelompokkan data berdasarkan usia, pendapatan, dan skor belanja, percobaan dilakukan dengan membandingkan jumlah cluster K=3 dan K=5 serta mengevaluasi hasilnya menggunakan Silhouette Score
Temuan Utama :
1. K-Means digunakan untuk mengelompokkan data berdasarkan kemiripan karakteristik usia, pendapatan, dan skor belanja
2. Pengujian dilakukan dengan jumlah cluster K=3 dan K=5 untuk melihat perbedaan hasil pengelompokan
3. Silhouette Score digunakan untuk membandingkan kualitas clustering, sedangkan scaling digunakan untuk mengurangi pengaruh perbedaan skala antarfitur
